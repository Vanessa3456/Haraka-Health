Haraka Health: AI-Powered Diagnostics for the Frontlines
Haraka Health is a rapid-response digital health platform designed to empower Community Health Volunteers (CHVs) in rural districts with instant, expert-level diagnostic capabilities. Built in a 60-minute sprint for the GDG Hackathon, the platform bridges the gap between remote villages and clinical expertise using Google's most advanced AI.

The Problem
In many rural areas, CHVs are the primary point of care but lack the tools to differentiate between common yet deadly illnesses like Malaria and Pneumonia. Manual data entry and slow reporting to health ministries often lead to delayed outbreak responses.

The Solution
Haraka Health provides a two-sided ecosystem:

CHV Field Tool: A mobile-optimized interface featuring:

Hands-Free Interaction: Integrated Web Speech API for voice-to-text symptom logging.

Multimodal AI Analysis: Powered by Gemini 1.5 Flash to analyze both text symptoms and physical photos (e.g., malnutrition screening) in real-time.

Ministry Dashboard: A high-level surveillance center that tracks real-time diagnostic trends and triggers "High Alert" notifications for specific districts (e.g., Kakamega) to prevent outbreaks.

Technical Stack
Engine: Google Gemini 1.5 Flash (Multimodal API)

Frontend: React, Tailwind CSS, Lucide Icons, Framer Motion

Prototyping: Google AI Studio & Google Cloud Console

Voice: Browser Native Web Speech API
